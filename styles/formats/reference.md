# Format: Reference Document

**Structure:**
1.  **Title:** Descriptive and formal.
2.  **Executive Summary:** A high-level overview of the document's contents and conclusions.
3.  **Table of Contents:** (Optional for short docs, mandatory for long ones).
4.  **Background / Methodology:** Context on sources and analysis methods.
5.  **Detailed Findings:**
    *   Organized by theme or topic.
    *   Include citations to source materials.
6.  **Recommendations / Next Steps:** Concrete actions based on findings.
7.  **Appendix:** Raw data, extra charts, or full transcripts.

**Constraints:**
- Use clear headings (H1, H2, H3).
- Ensure all claims are backed by citations (as per copilot-instructions.md).
