# Source Materials
**Enterprise Protocol:** This directory is the single source of truth for the Research Assistant.

## 🛡️ Data Governance
*   **NO PII/CSI:** Do not upload files containing Personally Identifiable Information or Sensitive Customer Information.
*   **Internal Only:** Ensure all uploaded documents are classified for Internal Use.

## ✅ Data Quality Checklist
Before ingesting, verify:
1.  [ ] **Freshness:** Is the data current (within the last quarter)?
2.  **Authority:** Is this a primary source (e.g., official report) vs. secondary (e.g., email chain)?
3.  **Completeness:** Are there missing pages or redacted sections that could skew analysis?
